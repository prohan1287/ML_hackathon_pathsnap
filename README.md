# PathSnap

GPS-to-road map matching using candidate generation, probabilistic classification and HMM/Viterbi decoding.

## Project structure

- `data_processing/` – trip loading and preprocessing
- `features/` – candidate features
- `models/` – candidate classifiers and experiment harness (Rohan K)
- `optimisation/` – Optuna Bayesian optimisation
- `hmm/` – sequence decoding
- `api/`, `ui/` – demo application
- `visualisation/` – maps and plots
- `results/` – experiment outputs
- `artifacts/` – selected model and feature list
- `report/` – report material

## Setup

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

Run model experiments after `results/candidates_train.parquet` and `results/candidates_student_test.parquet` are generated by the data/candidate pipeline:

```bash
python -m models.train
python -m optimisation.tune
```

Do not use evaluator trips for development or tuning.
